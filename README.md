# Список розсилки (Dapper)

Консольний додаток для теми «Використання Dapper» (ADO.NET): модель даних розсилки з країнами, містами, покупцями, розділами та акційними товарами.


## Структура даних

- **Countries** — країни
- **Cities** — міста (`CountryId`)
- **Buyers** — покупці (`CityId`), ПІБ та email
- **Sections** — розділи розсилки
- **BuyerSections** — підписка покупця на розділи (зв’язок покупець–розділ)
- **PromoProducts** — акційні товари (`SectionId`)

## Вимоги

- SQL Server Express LocalDB або інший SQL Server із рядком підключення у `Program.cs` 



Перший запуск створює базу `MailingListDapperDb` і таблиці, якщо їх ще немає.


## Завдання з ТЗ (меню програми)

| Пункт | Дія |
|------|-----|
| 1–5 | Вставлення: покупець, країна, місто, розділ, акційний товар |
| 6–10 | Оновлення відповідних сутностей |
| 11–15 | Видалення відповідних сутностей |
| 16 | Міста обраної країни |
| 17 | Розділи обраного покупця (`BuyerSections`) |
| 18 | Акційні товари обраного розділу |

При додаванні покупця можна через кому перелічити `SectionId`, щоб зв’язати його з розділами розсилки.


## Примітки

- Ціна вводиться у форматі з десятковою крапкою (InvariantCulture), наприклад `19.99`.
- При видаленні країни програма спочатку прибирає залежні записи покупців із відповідних міст, потім міста та саму країну.
- Основний код програмної логіки у **одному файлі `Program.cs`**, без коментарів у вихіднику.
